## 어려웠던 점 3가지와 해결
1. **검색·필터·정렬 순서 조합**: 검색어, 보기 필터, 정렬 기준이 따로 동작할 때 조건이 풀리는 문제가 있어 `getView()`에서 검색→보기 필터→정렬 순서로 처리하고 세 이벤트 모두 `refresh()`를 부르도록 통일했습니다[cite: 36, 39].
2. **카드 재렌더링 후에도 찜 상태 유지**: 검색이나 정렬로 카드를 다시 그릴 때 찜 상태가 사라지지 않도록 `liked` 배열을 `localStorage`에 저장하고 `renderCards`에서 `liked.includes(m.title)`로 클래스를 다시 적용했습니다[cite: 37, 39].
3. **찜 버튼 클릭 시 상세 모달 동시 열림 방지**: 보드 클릭 이벤트 위임에서 찜 버튼(`.like`)을 눌렀을 때 상세 대화상자까지 열리는 현상을 막기 위해 `e.target.closest(".like")` 처리 뒤 `return`하도록 작성했습니다[cite: 37, 38, 42].
